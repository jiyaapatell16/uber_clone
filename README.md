# Uber Clone as a Frontend project

A frontend learning project inspired by Uber's ride-booking experience, built with HTML and CSS with lightweight JavaScript interactions.

## Highlights

- Responsive Uber-inspired landing page
- Ride and navigation sections
- Pickup and dropoff inputs
- Ride price and scheduling actions
- Suggestions, reservation, business, FAQ and QR sections
- Basic client-side ride request validation
- Custom 404 page and favicon
- Deployment-friendly configuration

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Run locally

Open `index.html` in a browser or use a local development server such as VS Code Live Server.

## Disclaimer

This is an educational UI clone and is not affiliated with Uber. It does not process real rides, payments or user accounts.
